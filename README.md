# Гаджет Будущего №9: АНАЛИЗАТОР И РУСИФИКАЦИЯ БУРГЕРНЫХ НОВЕЛЛ

Утилита на базе ИИ для мгновенного перевода визуальных новелл с английского на русский язык.
Создано безумным первокурсником логистики в 9 утра.

![Кармен Distort](https://media1.tenor.com/m/Dm8nHN64xC0AAAAC/carmen-limbus-company.gif)


### Как это работает:
1. Жмешь `Win + Shift + S` и выделяешь область с текстом.
2. Локальная нейросеть `EasyOCR` вытаскивает буквы силами твоей видеокарты.
3. Локальная `Ollama` (или облачный `DeepSeek`) выдает сочный литературный перевод
   прямо в оверлей поверх игры.

<img src="https://media1.tenor.com/m/aw8ecOe1s-EAAAAC/untan-yui-hirasawa.gif" width="250" alt="Yui Untan">

### Главное в v1.4.3: видимый оверлей вместо консоли
В v1.4.0–v1.4.1 перевод печатался в консоль, а окна-оверлея не было вовсе. Если его
добавить «на админских правах», получается классическая проблема Windows: **UIPI**
(User Interface Privilege Isolation) запрещает процессу с высоким уровнем целостности
рисовать поверх окон обычных приложений. Оверлей создавался, перевод считался, но
окно было невидимым.

![DeepSeek](https://media.tenor.com/lACEh44nD0cAAAAi/deepseek.gif)

В v1.4.3 это исправлено архитектурно:
- `build.bat` **больше не собирает exe с `--uac-admin`** — приложение работает с обычными
  правами (asInvoker). Скриншоты через буфер обмена, глобальные хоткеи, OCR и HTTP
  работают без администратора.
- Появился настоящий оверлей: тёмная карточка со скруглёнными углами, всегда поверх
  окон, **прозрачная для кликов** (`WS_EX_TRANSPARENT`), не забирает фокус
  (`WS_EX_NOACTIVATE`) и не висит в панели задач (`WS_EX_TOOLWINDOW`).
- Текст оверлея DPI-осведомлён — при масштабе Windows 125/150% он остаётся чётким.

> Ограничение самой Windows: если игра запущена в **эксклюзивном полноэкранном**
> режиме, оверлей поверх неё не покажется (так работает DWM). Переключи игру в
> «оконный без рамки» — и всё видно.
>
> Не запускай лаунчер «от имени администратора»: это снова включает UIPI, и оверлей
> исчезнет. Лаунчер сам предупреждает об этом, если права повышены.

![Claude Code](https://media.tenor.com/zduaefgRHq4AAAAi/claude-claude-code.gif)


### Горячие клавиши
| Клавиша | Действие |
| --- | --- |
| `Win + Shift + S` | Выделить область с текстом (скриншот в буфер) |
| `F6` | Показать прошлый перевод ещё раз |
| `F7` | Скрыть / показать оверлей |
| `F8` | Пауза / продолжить |
| `F9` | Очистить память диалога |

Хоткеи регистрируются через Win32 `RegisterHotKey`, при конфликте — через `pynput`.



### Требования:
- Python 3.14
- Ollama (для локального перевода; по моделям смотреть в релизе)
- Pillow, easyocr, requests, pynput, numpy, customtkinter
- Установка зависимостей: `pip install -r requirements.txt`

### Запуск
```
python gui_launcher.py     # лаунчер (рекомендуется)
python main.py             # переводчик сразу, оверлей включён
python main.py --overlay-test --seconds 5   # проверить оверлей без OCR/моделей
```

### Лаунчер (GUI)
Тёмное окно на CustomTkinter позволяет:
- выбрать модель перевода — `Ollama (локально)` или `DeepSeek (облако)`;
- ввести API-ключ DeepSeek (хранится зашифрованным, см. ниже);
- указать имена моделей;
- настроить оверлей: позиция, прозрачность, размер текста, время показа, цвет,
  показ оригинала;
- запустить `main.py` в фоне кнопкой «Запустить переводчик» и остановить его;
- смотреть живой журнал переводчика прямо в лаунчере и открыть папку данных.

Настройки сохраняются в `data/settings.json`. При закрытии лаунчера фоновый процесс
переводчика автоматически завершается.

### Где лежат данные (память, словари, настройки, журнал)
Порядок выбора папки:
1. переменная окружения `GADGET_DATA_DIR`, если задана;
2. `data/` рядом с программой (portable-режим), если туда можно писать;
3. `%LOCALAPPDATA%\GadgetOfTheFuture\data` — если exe лежит в защищённой папке
   (например, `Program Files`), запись в которую недоступна.

Точный путь всегда виден в лаунчере (карточка «Где лежат данные», кнопка «Открыть
папку данных») и в журнале: `data_location_hint()`.

Файлы:
- `memory.json` — последние 15 реплик диалога (память для контекста);
- `characters.json` — найденный лор персонажей;
- `glossary.json` — глоссарий имён и терминов;
- `web_cache.json` — кэш поиска DuckDuckGo;
- `settings.json` — настройки и API-ключ (шифруется через Windows DPAPI);
- `gadget.log` — журнал работы переводчика.

В релизный архив эти файлы **не попадают**: сборка кладёт рядом с exe только
`config.py` и пустую `data/`.

### DeepSeek API
DeepSeek — облачная модель с OpenAI-совместимым API. Чтобы её использовать:
1. Получи API-ключ на https://platform.deepseek.com.
2. Запусти лаунчер и выбери «DeepSeek (облако)».
3. Вставь ключ и нажми «Запустить переводчик».

В этом режиме перевод идёт через `https://api.deepseek.com/chat/completions` (модель по
умолчанию `deepseek-chat`), локальная Ollama для перевода не нужна.
Ключ хранится в `settings.json` в зашифрованном виде (`dpapi:...`): расшифровать его
можно только на этой машине и только под этим пользователем Windows.

### Интернет-доступ (DuckDuckGo):
Если локальная модель встречает неизвестное слово или имя — гаджет ищет его в
DuckDuckGo и добавляет найденный контекст в промпт перевода. Настройки в `config.py`
(`ENABLE_WEB_SEARCH`, `USE_MODEL_UNKNOWN_CHECK`, `MAX_SEARCH_TERMS`). Кэш найденного
хранится в `data/web_cache.json`.

При обнаружении нового персонажа гаджет ищет его лор в DuckDuckGo (запросы вида
«"Имя" visual novel wiki» / «"Имя" fandom») и сохраняет описание в
`data/characters.json`. Если интернет ничего не нашёл — делает фоллбэк на локальную
модель `gemma2` с жёстким лимитом в 1 предложение.

### Сборка exe
```
build.bat
```
Результат: `dist\GadgetOfTheFuture\GadgetOfTheFuture.exe` и готовый архив

это обязательное условие работы оверлея.
