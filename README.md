# Гаджет Будущего №9: АНАЛИЗАТОР И РУСИФИКАЦИЯ БУРГЕРНЫХ НОВЕЛЛ

Утилита на базе ИИ для мгновенного перевода визуальных новелл с английского на русский язык. 
Создано безумным первокурсником логистики в 9 утра в Перми.

### Как это работает:
1. Жмешь `Win + Shift + S` и выделяешь область с текстом.
2. Локальная нейросеть `EasyOCR` вытаскивает буквы силами твоей видеокарты.
3. Локальная `Ollama` (модель `qwen2.5:7b`) выдает сочный литературный перевод прямо в консоль.

### Требования:
- Python 3.14 (потому что мы опережаем время)
- Видеокарта уровня RTX 3050 (8GB)
- Установленная Ollama

- вообще со временем я повожусь с кодом и уберу лишнее и поменяю имя ответчика.
