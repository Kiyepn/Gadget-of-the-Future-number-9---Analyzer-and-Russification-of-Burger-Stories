# Гаджет Будущего №9: АНАЛИЗАТОР И РУСИФИКАЦИЯ БУРГЕРНЫХ НОВЕЛЛ

Утилита на базе ИИ для мгновенного перевода визуальных новелл с английского на русский язык. 
Создано безумным первокурсником логистики в 9 утра.

### Как это работает:
1. Жмешь `Win + Shift + S` и выделяешь область с текстом.
2. Локальная нейросеть `EasyOCR` вытаскивает буквы силами твоей видеокарты.
3. Локальная `Ollama` (или облачный `DeepSeek`) выдает сочный литературный перевод прямо в консоль.

### Требования:
- Python 3.14
- Ollama (для локального перевода; по моделям смотреть в релизе)
- Pillow, easyocr, requests, keyboard, numpy, customtkinter
- Установка зависимостей: `pip install -r requirements.txt`

### Лаунчер (GUI)
Запускается командой:
```
python gui_launcher.py
```
Тёмное окно на CustomTkinter позволяет:
- выбрать модель перевода — `Ollama (локально)` или `DeepSeek (облако)`;
- ввести API-ключ DeepSeek;
- указать имена моделей;
- запустить `main.py` в фоне кнопкой «Запустить переводчик» и остановить его.

Настройки сохраняются в `data/settings.json` (файл в `.gitignore`, поэтому ключ не попадёт в репозиторий). При закрытии лаунчера фоновый процесс переводчика автоматически завершается.

### DeepSeek API
DeepSeek — облачная модель с OpenAI-совместимым API. Чтобы её использовать:
1. Получи API-ключ на https://platform.deepseek.com.
2. Запусти лаунчер и выбери «DeepSeek (облако)».
3. Вставь ключ и нажми «Запустить переводчик».

В этом режиме перевод идёт через `https://api.deepseek.com/chat/completions` (модель по умолчанию `deepseek-chat`), локальная Ollama для перевода не нужна.

### Интернет-доступ (DuckDuckGo):
Если локальная модель встречает неизвестное слово или имя — гаджет ищет его в DuckDuckGo и добавляет найденный контекст в промпт перевода. Настройки в `config.py` (`ENABLE_WEB_SEARCH`, `USE_MODEL_UNKNOWN_CHECK`, `MAX_SEARCH_TERMS`). Кэш найденного хранится в `data/web_cache.json`.

При обнаружении нового персонажа гаджет ищет его лор в DuckDuckGo (запросы вида «"Имя" visual novel wiki» / «"Имя" fandom») и сохраняет описание в `data/characters.json`. Если интернет ничего не нашёл — делает фоллбэк на локальную модель `gemma2` с жёстким лимитом в 1 предложение.
