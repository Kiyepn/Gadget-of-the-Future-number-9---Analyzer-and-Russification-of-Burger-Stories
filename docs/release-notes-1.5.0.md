# GadgetOfTheFuture v1.5.0 — Lightweight (Windows Native OCR)

Готовый текст для GitHub Release (страница релиза на русском). Скопировать в
описание релиза, файлы приложить из `dist\`.

---

## Что нового

**OCR переведён с EasyOCR на системный движок Windows** (`Windows.Media.Ocr`).
Из-за этого из дистрибутива ушли torch и torchvision — сборка стала в 20 раз
легче и запускается без скачивания моделей.

| | v1.4.3 | v1.5.0 |
| --- | --- | --- |
| Папка с программой | 938 МБ | **45,2 МБ** |
| Архив релиза | сотни МБ | **22,32 МБ** |
| Готовность OCR при старте | ~6 с | **0,07 с** |
| Распознавание кадра | 0,7–0,9 с (CPU) | **10–40 мс** |
| Что качается при первом запуске | модели EasyOCR | **ничего** |

## Что скачивать

1. **`GadgetOfTheFuture-v1.5.0.zip`** — сама программа (22,32 МБ). Распаковать
   целиком и запустить `GadgetOfTheFuture.exe`. Права администратора не нужны.
2. **`GadgetOfTheFuture-v1.5.0.zip.sha256`** — контрольная сумма архива:

   ```
   30ef810e94a56be51e9ddf43afd07d75a48189af2642a12eadde795d0c9b4219
   ```

   Проверка: `Get-FileHash .\GadgetOfTheFuture-v1.5.0.zip -Algorithm SHA256` —
   хэш должен совпасть.

Требования к системе:

- Windows 10 или 11 (64-бит);
- **языковой пакет OCR для английского** — Параметры → Время и язык → Язык →
  Добавить язык → English (United States). Уже есть на большинстве машин;
- для перевода: локальный [Ollama](https://ollama.com) + модель
  (`ollama pull translategemma:4b`, 3.3 ГБ) **или** API-ключ DeepSeek.

Ничего из перечисленного (кроме самого архива) программа сама не скачивает.

## Изменения

- **Windows Native OCR**: новый провайдер `brain/ocr_providers/win_ocr.py`.
  Два бэкенда с автоматическим откатом: `winrt` (быстрый) и PowerShell 5.1
  (запасной, если пакеты winrt недоступны). Интерфейс совместим с EasyOCR
  (`read_text` / `extract_text` / `readtext`).
- **Выбор провайдера**: `"ocr_provider": "windows" | "easyocr"` в
  `data/settings.json` (по умолчанию `windows`).
- **EasyOCR остался в исходниках** как экспериментальный режим: зависимости
  вынесены в `requirements-easyocr.txt`, старый прототип — в `legacy/`.
- **Сборка**: `--collect-all winrt`, явные исключения torch/easyocr/numpy/cv2 и
  пр.; ZIP содержит одну папку `GadgetOfTheFuture` и `README.txt` для
  пользователя.
- **Надёжность OCR**: один сбойный кадр больше не выключает распознавание,
  пустой кадр не запускает PowerShell, ошибка запуска показывается в оверлее.
- **Тесты**: 43 теста (19 новых — Windows OCR), в том числе в чистом окружении
  без torch/easyocr.

## Известные ограничения

- Нужен английский языковой пакет OCR (без него в журнале будет понятная ошибка).
- Эксклюзивный полноэкранный режим игры: оверлей не показывается (ограничение
  Windows; переключи игру в «оконный без рамки»).
- `exe` не подписан сертификатом, поэтому SmartScreen может показать
  предупреждение. Сверь SHA256.
- Анализ лора персонажей использует модель `gemma2:9b` (если её нет — работает
  веб-поиск, а лор просто не пополняется).
