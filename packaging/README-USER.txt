ГАДЖЕТ БУДУЩЕГО №9 — v1.5.0-beta (Lightweight)
=================================================

Что это
-------
Переводчик текста из визуальных новелл: скриншот -> распознавание текста ->
перевод -> карточка поверх игры.


Как запустить (коротко)
-----------------------
1. Распакуй архив целиком в любую папку (например, на рабочий стол).
   Не запускай exe прямо из ZIP — приложение не сможет писать журнал.
2. Запусти GadgetOfTheFuture.exe (двойной клик).
3. В лаунчере выбери модель перевода:
   * Ollama (локально) — нужен установленный Ollama и скачанная модель;
   * DeepSeek (облако) — нужен API-ключ с platform.deepseek.com.
4. Нажми «Запустить переводчик».
5. В игре: Win+Shift+S -> выдели область с текстом -> перевод появится
   в карточке поверх окна.


Что нужно на компьютере
-----------------------
* Windows 10 или Windows 11 (64-бит).
* Языковой пакет OCR для английского языка. Проверить: Параметры ->
  Время и язык -> Язык и регион -> добавить «English (United States)».
  Без него в журнале появится ошибка «Windows OCR недоступен».
* Ollama (для локального перевода) или ключ DeepSeek (для облачного).
* Права администратора НЕ нужны. Наоборот: если запустить от администратора,
  карточка перевода может не отображаться поверх игры (ограничение Windows UIPI).


Горячие клавиши
---------------
F6 — показать прошлый перевод ещё раз
F7 — скрыть / показать карточку
F8 — пауза / продолжить
F9 — очистить память диалога


Где лежат данные и журнал
-------------------------
Папка data рядом с exe:
  data\gadget.log      — журнал работы (начинай диагностику с него);
  data\settings.json   — настройки и зашифрованный API-ключ;
  data\memory.json     — последняя память диалога;
  data\characters.json — найденный лор персонажей;
  data\glossary.json   — глоссарий имён;
  data\web_cache.json  — кэш поиска.

Удалить эти файлы — значит сбросить память и настройки приложения.


Если что-то не работает
-----------------------
1. Загляни в data\gadget.log — там видно, какой OCR используется:
   «Используется OCR: Windows Native» — всё в порядке.
2. «Windows OCR недоступен» — установи английский языковой пакет Windows
   (см. выше), затем перезапусти приложение.
3. Перевод не появляется, но текст распознан — проверь, что запущен Ollama
   (или введён верный ключ DeepSeek), смотри ошибки в журнале.
4. Карточка не видна поверх игры — переключи игру в режим «оконный без рамки»:
   в эксклюзивном полноэкранном режиме Windows не показывает окна поверх.
5. Windows SmartScreen/антивирус ругается на exe — сборка не подписана
   сертификатом (подпись платная), это обычное поведение для новых
   неподписанных программ. Запускать можно через «Подробнее -> Выполнить»,
   если ты скачал архив с официальной страницы проекта.
